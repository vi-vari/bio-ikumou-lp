# ビオ接骨院 小牧院（育毛治療院）LP

Figma デザイン（[LP / node 444:5](https://www.figma.com/design/Nd86bU4YvLSdwvI1IjcYkD/LP?node-id=444-5)）を
もとに実装した、レスポンシブ対応のランディングページです。
テーマは「薬なしで、育毛が叶う。」ダークネイビー × ゴールドの高級感あるデザイン。

## 構成

```
.
├── index.html        # ページ本体（1カラム LP・全25セクション）
├── css/style.css     # スタイル（デザイントークン + レスポンシブ）
├── js/script.js      # LINE リンク一括設定 + 固定 CTA 制御
└── images/bio/       # 写真アセット（下記マニフェスト参照）
```

## レスポンシブ

- モバイルファースト。コンテンツは最大 `680px` 幅で中央寄せ（Figma 原寸）。
- 見出し・余白は `clamp()` でビューポートに応じて可変。
- 3つの安心ポイントは 400px 未満で1カラム、ビフォーアフターは 400px 未満で縦積み。
- OUTSIDE/INSIDE カードは 360px 未満で1カラム。
- 画面下に **スクロール追従の固定 CTA バー**を常時表示（フッター到達時のみ退避）。
- `prefers-reduced-motion` に対応。

## 設定が必要な項目

- **LINE URL**: `js/script.js` の `LINE_URL` に実際の LINE 追加 URL を設定してください。
  設定すると全 CTA ボタン（画面下 固定 CTA を含む）に反映されます（未設定時は `#`）。
- **Googleマップ**: `index.html` の ACCESS セクション `iframe` は住所「愛知県小牧市北外山710-3」で
  埋め込んでいます。正確な地点に変えたい場合は `q=` を差し替えてください。
